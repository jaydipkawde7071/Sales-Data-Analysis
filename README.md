# Sales Data Analysis Project

## 📸 Sales Analysis Dashboard

![Sales Analysis Dashboard](sales_dashboard.png)
## Project Overview

This project analyzes sales data using Python, Pandas, and Matplotlib.

## Objectives

* Calculate total sales.
* Analyze product-wise sales.
* Analyze region-wise sales.
* Analyze monthly sales.
* Identify the best-selling product.
* Create graphs to visualize sales.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook
* Excel

## Project Files

* Sales_Data_Analysis.ipynb
* Sales_Analysis_Report.xlsx

## Dataset

This project uses sample sales data created for learning and demonstration purposes.
